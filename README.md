## 🚀 Featured Projects

### RAM-Link
**Experimental Android RAM-over-USB research project**

Explores using Android device memory as a remotely addressable resource over a physical USB connection.

Current architecture:

```
Windows / Linux / macOS
        ↓
RAM-Link client / adapter
        ↓
RML1 protocol
        ↓
USB networking
        ↓
Android / Termux
        ↓
Android RAM buffer
```

Current work includes a RAM protocol, Android server, Windows client, block-device testing, and a Windows virtual filesystem adapter.

🔗 [View RAM-Link](https://github.com/richie960/ram-link)
